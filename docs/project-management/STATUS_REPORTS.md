# Status Reports

## Initial baseline

FocalDesk is in alpha. The repository roadmap records release automation and manifest-based install verification as complete. Current stabilization priorities include compositor recovery, display and application compatibility, and session and service lifecycle. This baseline records the documented state. Candidate validation belongs in a dated report.

See the [project status](../../README.md#project-status) and [repository roadmap](../../ROADMAP.md).

## Report template

Copy this format for a release candidate or a material priority change.

- Date and reporting period
- Revision or candidate tag
- Completed work and evidence
- Checks run, environments covered, and results
- Blockers, risk changes, and decisions needed
- Next priorities and related issues
