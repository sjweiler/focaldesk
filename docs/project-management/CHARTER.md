# FocalDesk Project Charter

FocalDesk is a solo-maintained alpha Linux desktop environment built around a custom Wayland compositor. It aims to provide a responsive, keyboard-first desktop with predictable workspaces, a cohesive visual design, and permissioned automation.

## Objectives

- Stabilize session startup, recovery, and everyday window and input behavior.
- Validate display behavior and application compatibility on recorded configurations.
- Make alpha builds, installation, and removal reproducible.
- Keep automation and AI capabilities observable and subject to explicit permission.

The project owner sets priorities and makes merge and release decisions. Use [Scope](SCOPE.md) for project boundaries, the [Project Roadmap](ROADMAP.md) for priorities, and the [Release Plan](RELEASE_PLAN.md) for alpha readiness.
