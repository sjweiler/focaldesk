# Stakeholders

| Stakeholder | Role | How to engage |
| --- | --- | --- |
| Project owner | Sets direction and decides what to merge and release | Issues and pull requests |
| Contributors | Propose changes, provide patches, and document validation | Focused pull requests with affected services or backends and test evidence |
| Alpha users and testers | Report usability, hardware, and application compatibility findings | Reproducible issues with the tested revision and environment |
| Security reporters | Report potential vulnerabilities | Private reporting channel in the security policy |

Follow the [contributor guide](../../CONTRIBUTING.md) for normal reporting and the [security policy](../../SECURITY.md) for sensitive findings.
